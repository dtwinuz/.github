# Xavfsizlik siyosati

## Zaiflik haqida xabar berish

Zaiflikni **ochiq issue, PR yoki discussion'da yozmang.**

1. **Public repo** bo'lsa (masalan `teletwin-web`): repoda **Security → Report a vulnerability** tugmasini bosing (GitHub private vulnerability reporting).
2. **Private repo** bo'lsa yoki tugma ko'rinmasa: email yuboring — **nosirbek.tech@gmail.com**, mavzu: `[SECURITY] <repo>: <qisqa tavsif>`. Private repolarda bu tugma GitHub tomonidan berilmaydi.

Xabarda quyidagilarni yozing:
- ta'sirlangan repo, URL yoki versiya;
- qayta chiqarish qadamlari yoki PoC;
- ta'sir darajasi: qanday ma'lumot yoki huquq xavf ostida.

## Javob muddatlari

| Bosqich | Muddat |
|---|---|
| Xabar olinganini tasdiqlash | 7 kun ichida |
| Tekshirish va xavf darajasi (CVSS) | 14 kun ichida |
| Tuzatish va reliz (yuqori/kritik) | 60 kun ichida, iloji bo'lsa tezroq |

Bu muddatlar barcha dtwinuz va wonmortech repolarida hamda https://wonmor.io/security sahifasida bir xil.

Tuzatish chiqarilgandan keyin, roziligingiz bo'lsa, hissangizni Release yoki advisory'da ko'rsatamiz.

## Qo'llab-quvvatlanadigan versiyalar

Faqat `main` branch va eng so'nggi Release qo'llab-quvvatlanadi.
